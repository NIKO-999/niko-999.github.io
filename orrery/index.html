        The top folder files the note. A category line in the note’s own frontmatter outranks the folder, and re-filing by hand on the map outranks both.

        You pick the folder once. Where the browser can remember a folder, Attach reconnects it after a permission prompt; where it cannot, you pick it again — that is the browser’s trade, not a fault here.

        Every .md file inside is read where it sits. Dot-folders — settings, trash — are skipped. It stops at 4,000 notes and says so in the log rather than pretending it read everything.

        [[Links]] resolve by exact path, then by filename, then by filename ignoring case. One that lands nowhere is a loose end, and the map counts them: a gap you can see is a note you meant to write.

        Read-only, always. Nothing uploads and nothing is written back. The parsed copy is cached in this browser so the map opens before you reconnect; Forget drops that copy and touches nothing on your disk.
