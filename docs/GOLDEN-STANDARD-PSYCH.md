# GOLDEN STANDARD — Gene Keys psychological-profile writing

This governs `gene-keys.html` only. It replaces the old Shadow → Gift →
Siddhi spiritual-arc rules (kept below in `GOLDEN-STANDARD.md` history for
the Destiny Matrix site, which is a separate product with its own voice).
Gene Keys is now framed as a psychological/behavioral profile: same 64-key
calculation, a completely different interpretive layer — mindset, wiring,
wounds, behavior, blind spots — not spiritual growth or enlightenment.

## Who is writing
A sharp behavioral writer, not a guru. Direct, specific, a little clinical in
the best sense — like a good psychologist who has actually watched you do the
thing, not a horoscope. Never therapist-soft, never mystical, never framed as
a path to enlightenment. The reader should feel *seen*, not *guided*.

Always second person, present tense, addressed as "you."

## Structure — five fields, no more
wiring              2-4 sentences.
root                2-4 sentences.
defaultMode         2-4 sentences.
blindSpot           2-4 sentences.
underusedStrength   2-4 sentences.

## WIRING — 2-4 sentences
Flatly states the core behavioral pattern — what this person actually DOES,
not what they're becoming or striving toward. No achievement framing, no
"you have mastered." This is a fact about how they're built, stated as
observation, not aspiration.

Present tense. NO hedging: no "can," "tends to," "sometimes," "may."

**Wiring is about the PERSON's actual behavior — never about the mechanism.**
Never open by explaining what the key measures or how it's calculated.

## ROOT — 2-4 sentences
Where this pattern likely comes from — early, formative, but never a diagnosis
and never blaming a specific person or event the content can't actually know.
Contextualize, don't accuse: "What got rewarded early was X, so X became the
default" rather than "your parents did X to you."

This is NOT a retelling of Wiring in the past tense — it answers a different
question (why does this exist) not the same one again (what does it look
like).

## DEFAULT MODE — 2-4 sentences
What this person actually does under stress, pressure, or when triggered —
the automatic, often unhelpful version of the same wiring. Concrete and
observable: an actual behavior, not a mood. Traces a real cost where relevant.
This is close to what "shadow" used to cover, but narrower and behavioral —
the reflex, not the whole failure mode.

## BLIND SPOT — 2-4 sentences
What this person consistently cannot see about themselves here — the thing
other people notice before they do. Different from Default Mode: Default
Mode is the visible behavior; Blind Spot is the gap in their own
self-perception that lets that behavior keep running unexamined.

## UNDERUSED STRENGTH — 2-4 sentences
The same wiring's real, usable advantage — not a mystical reward, not an
enlightenment endpoint, just the practical upside most people with this
pattern never actually access because they're busy fighting the Default
Mode version of it. No question format, no "You are allowed to...", no
exercise/instruction framing. A statement, not an invitation.

## Weaving the key number
Connect the key to lived behavior; never define it.
  YES: "the pattern in you that provokes a stuck room into moving again"
  NO:  "Key 39 represents provocation"
Never open an interpretation by naming or defining the key number.

## Position changes meaning
The same key is never interpreted identically across the 13 spheres. If a key
appears in multiple positions across this site (it always does — each role
file has its own reading of every key), every interpretation is written FRESH
for that sphere's specific lens (career for Life's Work, body for Radiance,
relationships for Attraction, etc.). Never reuse or lightly reword across
spheres.

## Prohibitions
- No hedging language anywhere.
- No repeated openers across the 64 entries in a file ("You tend to," "There's
  a part of you that…"). Check across the whole set before shipping.
- No metaphor stacking. Grounded, sparing metaphors only.
- No bullet points, numbered lists, or headings inside interpretations —
  flowing prose.
- No rhetorical questions anywhere in these five fields (that device belonged
  to the old Invitation field, which no longer exists).
- No spiritual language: retire "siddhi," "mastery" (as an achieved state),
  "transcend," "enlighten," "sacred," "awakening," "the gift of."
- No clinical coldness either — specific and direct, not sterile.
- No positive/negative state labels.
- Never fabricate the reader's age or life stage.
- Never present any of it as objective fact — it's a symbolic system offered
  for self-recognition, not a diagnosis.

## Sourcing
Never invent a mechanism this codebase doesn't already compute. If unsure
whether a claim about the underlying key theme is accurate, ground it in the
existing Shadow/Gift/Siddhi triad content already written for that key
(`js/gene-keys-content.js`) as the thematic source material — the FEELING and
subject matter carries over, only the framing changes from spiritual arc to
psychological profile.

## Before shipping
Check every entry: all five fields present, each 2-4 sentences; no duplicated
openers anywhere in the set; no leftover spiritual-arc vocabulary; each of the
five answers a genuinely different question (grep for near-duplicate phrasing
between a key's own Root and Default Mode, the most common overlap risk).
